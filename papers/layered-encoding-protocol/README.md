# Layered Encoding Protocol Paper

This directory contains materials related to the paper:

**Yurii Kulakov, Oleksandr Havryliuk**  
**A Review of Data Encoding Problems in Barcodes and a Layered Encoding Protocol Based on the OSI Model**

## Overview

This paper analyzes structural limitations of data encoding in barcode systems and proposes a layered interpretation of barcode payload processing based on the OSI reference model.

The main focus of the paper is the Self-Identified Transport Protocol (SITP), a lightweight transport-layer mechanism for explicit identification of nested barcode payload encoding schemes. The proposed approach is intended to improve protocol identification, support extensible payload formats, and preserve compatibility with existing barcode symbologies by operating above the barcode encoding layer.

## Experimental materials

This directory contains the reproducibility materials used for the experimental revision of the paper.

### Dataset

The `dataset` directory contains the 16 MiB SITP random baseline dataset used for false-positive detection experiments:

- `sitp-baseline.bin` — binary random dataset;
- `sitp-baseline.sha256` — SHA-256 checksum of the binary dataset;
- `sitp-baseline.md` — dataset description and generation metadata.

The dataset was generated using the operating-system cryptographically secure random number generator exposed through:

`System.Security.Cryptography.RandomNumberGenerator.GetBytes`

### Results

The `results` directory contains the outputs generated by the SITP experimental software:

- `sitp-decode-stability.xml` — all SITP messages accidentally detected during byte-wise scanning of the random dataset;
- `sitp-decode-stability-statistics.txt` — aggregated false-positive detection statistics for each SITP mode;
- `sitp-encode-decode-speed.txt` — SITP encoding and decoding performance measurements.

The stability experiment attempts to decode a SITP message at every byte offset of the random dataset. Since the dataset contains no intentionally inserted SITP messages, every successfully decoded message is treated as a false-positive detection.

## Reproducing the experiments

The implementation and research programs used to generate these materials are located in the repository-level `sitp-stability` directory.

The experimental workflow consists of:

1. generating or loading the random baseline dataset;
2. validating the dataset SHA-256 checksum;
3. scanning the dataset from every byte offset;
4. storing all detected SITP messages in XML;
5. aggregating false-positive statistics by SITP mode;
6. measuring complete SITP encoding and decoding execution time.

The generated files in this directory are publication-oriented copies of the corresponding dataset and experimental outputs.

## Experimental scope

The decode-stability experiment evaluates unrestricted byte-wise scanning of random binary data. It does not represent the more constrained whole-barcode detection scenario, in which SITP decoding starts at offset zero and the decoded SITP message is required to occupy the complete barcode payload.

The performance measurements represent complete encode and decode operations, including memory allocation, LCG mask generation, XOR masking, CRC processing, and message object construction.

## Relation to the repository

This paper is part of the broader `barcode-sitp-research` repository, which contains research code and experimental materials for SITP-based barcode encoding, ESID design, and related academic studies.

This directory contains paper-specific datasets and experimental results. Shared implementation code, reusable research utilities, and experiment-generation programs are maintained in the repository-level `sitp-stability` directory.
